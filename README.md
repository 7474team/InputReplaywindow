# 自動化操作腳本工具

這是一個基於 Python 和 PySide6 開發的自動化操作工具，能夠記錄和重放鍵盤輸入和滑鼠操作，幫助用戶自動化重複性任務。

## 功能特點

- **記錄和重放**：記錄鍵盤輸入和滑鼠操作，並能夠重放這些操作
- **實時錄製**：支持實時錄製用戶的操作 (可能有痕多BUG 但我沒管他)
- **多種操作類型**：
  - 鍵盤輸入（包括普通文字(可大串文字)、特殊按鍵和組合鍵）
  - 滑鼠移動
  - 滑鼠點擊（左鍵/右鍵，單擊/雙擊）
- **操作序列管理**：可以添加、刪除、上移、下移操作步驟
- **全局熱鍵**：使用 F9 鍵觸發腳本執行，即使應用程序不在焦點狀態

## 技術實現

- **UI 框架**：使用 PySide6 (Qt for Python) 構建用戶界面
- **自動化庫**：
  - `pyautogui`：用於模擬滑鼠移動和點擊
  - `keyboard`：用於模擬鍵盤輸入和監聽按鍵
  - `mouse`：用於監聽滑鼠事件
  - `pyperclip`：用於剪貼板操作，處理中文等複雜文字輸入
- **多線程**：使用 Python 的 `threading` 模塊實現背景任務
- **UI 主題**：使用 `qt_material` 提供現代化的 UI 主題

## 使用方法

### 添加操作

1. **添加滑鼠點擊**：
   - 設置點擊類型（左鍵/右鍵，單擊/雙擊）
   - 點擊 "滑鼠點擊" 按鈕

2. **添加滑鼠移動**：
   - 輸入目標 X、Y 坐標
   - 設置移動速度
   - 點擊 "滑鼠移動" 按鈕

3. **添加鍵盤輸入**：
   - 在文本框中輸入要模擬的按鍵或文字
   - 點擊 "鍵盤輸入" 按鈕

4. **實時錄製**：
   - 點擊 "開始錄製" 按鈕
   - 執行您想要記錄的操作
   - 按 ESC 鍵結束錄製

### 管理操作序列

- **刪除操作**：選擇操作後點擊 "刪除" 按鈕
- **上移操作**：選擇操作後點擊 "上移" 按鈕
- **下移操作**：選擇操作後點擊 "下移" 按鈕

### 執行自動化操作

- 點擊 "執行" 按鈕或按 F9 鍵開始執行操作序列

## 特殊功能說明

### 鍵盤輸入處理

- **普通文字**：直接使用剪貼板方式輸入，支持中文等複雜字符
- **特殊按鍵**：如 Enter、Tab、Esc 等，使用 keyboard 模塊直接處理
- **組合鍵**：如 Ctrl+C、Alt+Tab 等，使用 "+" 連接各個按鍵

### 全局熱鍵

- 使用 F9 鍵作為全局熱鍵，即使應用程序不在焦點狀態也能觸發執行
- 實現了冷卻時間機制，避免意外的重複觸發

## 安裝依賴

```bash
pip install PySide6 pyautogui keyboard mouse pyperclip qt-material
```

## 開發與擴展

本工具使用模塊化設計，便於擴展新功能：

- `WidgetA_UiEN13231` 類是主要的應用程序類，處理 UI 交互和自動化邏輯
- 可以通過添加新的操作類型來擴展功能，只需在 `GO_pushbuttoned` 方法中添加相應的處理邏輯

## 注意事項

- 自動化操作可能會影響您當前正在使用的應用程序，請謹慎使用
- 某些應用程序可能有安全限制，阻止自動化操作
- 在執行包含敏感操作的腳本前，建議先在安全環境中測試
